## Multiple-choice questions

1. For relevant {a,c} and ranking [b,c,a], Recall@2 is:

   - A. 0
   - B. 1/2
   - C. 1
   - D. 2

2. A first relevant result at rank 4 contributes reciprocal rank:

   - A. 4
   - B. 0
   - C. 1/4
   - D. 1/2

## Conceptual questions

1. Calculate Recall@k and reciprocal rank from a two-relevant-document example, including one query with no relevant hit.
2. Distinguish an answerable query with a failed retrieval from a no-relevant query and describe the reporting denominator for each.

## Practical assignment

Complete [the module lab](../labs/lab-06.md). Submit its worksheet, proposed tests, and the independent failure example. Code execution belongs to later learner work, not to material preparation.

## Debugging scenario

Attempt both lecture debugging scenarios. Identify the failure boundary, a reproducible minimal case, the expected safe behavior, and the test that would prevent regression.

## Review criteria

- Both multiple-choice answers correct and justified.
- Conceptual answers connect the mechanism to a concrete failure.
- Lab acceptance criteria and counterexample are reviewable.
- No invented model-quality, latency, or completion result.
