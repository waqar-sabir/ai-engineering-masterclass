## Build progression

1. Labs 1–2 establish vector/collection/point contracts and Qdrant operations.
2. Lab 3 defines the manual RAG and cited-answer contract.
3. Labs 4–5 establish chunking, provenance, refresh, and deletion.
4. Labs 6–7 map the known pipeline to LangChain and test parity.
5. Lab 8 specifies four-format parsing and quality checks.
6. Lab 9 inspects retrieval variants without implementing the Phase 4 stack.
7. Lab 10 integrates the design and review package.

During course preparation, these are materials and future implementation tasks only. Reuse lab components during the implementation pass; do not duplicate the project in ten separate folders.
