## Multiple-choice questions

1. A retriever’s core responsibility is:

   - A. Select source documents/passages
   - B. Update model weights
   - C. Authorize every tenant
   - D. Prove all answers true

2. A fake model test can establish:

   - A. Actual model quality
   - B. Real token pricing
   - C. Live provider latency
   - D. Orchestration and output-contract behavior

## Conceptual questions

1. What does a retriever return? Give a concrete counterexample and the expected safe behavior.
2. Does invoke mean provider equivalence? Explain the invariant and how a later test would detect its violation.

## Practical assignment

Complete [the module lab](../labs/lab-06.md); submit its artifact plus an independent failure fixture. Execution belongs to the later implementation pass.

## Debugging scenarios

Attempt both lecture debugging questions. For each, identify the earliest failing stage, the observed evidence, the safe response, and a regression test. Do not assume a model/framework/database change is the first fix.

## Review criteria

- Both multiple-choice answers correct and justified.
- The module-specific contract and counterexample are concrete.
- Lab and failure evidence cover every acceptance criterion.
- No unrun project test, quality score, or completion is claimed.
