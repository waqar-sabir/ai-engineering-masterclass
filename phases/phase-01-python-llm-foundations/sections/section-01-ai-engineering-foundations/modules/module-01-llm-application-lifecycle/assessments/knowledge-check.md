# Module 1.1.1 — knowledge check

[Module home](../README.md)

Formative assessment. Answer in your own words and include the exercise artifact. There is no assigned numeric score; use the lecture completion criteria and request review if any explanation is uncertain.

## Lecture 01

1. Which responsibilities remain with the application even if the model follows instructions well?
2. Why is an LLM output closer to untrusted API input than to a deterministic function return?
3. Name one evaluation metric for product quality and one for operations.

## Lecture 02

1. Why can two strings of equal character length use different token counts?
2. Which latency measure matters most for a streaming UI?
3. When might self-hosting be justified?
4. Why should model names and limits be configuration, not scattered constants?

## Review criteria

- Explain the mechanism rather than restating a term.
- Identify one failure case and its application-level control.
- Distinguish measured results from assumptions.
