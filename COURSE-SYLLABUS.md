# Course syllabus

The sequence and milestones below come from the supplied Notion roadmap. Prerequisites are repository planning guidance. Phase 1–2 materials are Approved; learner completion and Phases 3–10 remain Planned.

## Phase 01 — Python + LLM Foundations (Days 1–7)

Outcome: Design typed Python LLM applications with provider boundaries, reliable HTTP/async I/O, structured contracts, evidence checks, and versioned prompts.

Prerequisite: course prerequisites.

Milestone specification: **AI Research Assistant**, with an **Invoice Processing** structured-output lab. Materials: Approved; implementations: Planned. Three sections, six modules, twelve lectures, four labs, and a 100-point assessment. [Phase materials](phases/phase-01-python-llm-foundations/README.md).

## Phase 02 — LLM Internals + Embeddings (Days 8–14)

Outcome: Understand how LLMs and embeddings work well enough to design reliable AI applications.

Prerequisite: Phase 1 outcomes.

Milestone specification: **Document Semantic Search**, a local exact-search baseline with reproducible encoder/snapshot contracts and frozen-query evaluation. Materials: Approved; implementation: Planned. Four sections, seven modules, fourteen lectures, seven guided labs, dedicated system design, and separate assessment solutions. [Phase materials](phases/phase-02-llm-internals-embeddings/README.md) · [Detailed phase syllabus](phases/phase-02-llm-internals-embeddings/syllabus.md).

## Phase 03 — Vector Databases + RAG (Days 15–24)

Outcome: Build a complete RAG pipeline.

Prerequisite: Phase 2 outcomes.

Planned milestone: **Enterprise Knowledge Assistant**. [Phase overview](phases/phase-03-vector-databases-rag/README.md).

## Phase 04 — Advanced RAG (Days 25–31)

Outcome: Move from a demo RAG system to production-quality retrieval.

Prerequisite: Phase 3 outcomes.

Planned milestone: **Multi-Tenant Enterprise RAG**. [Phase overview](phases/phase-04-advanced-rag/README.md).

## Phase 05 — AI Agents (Days 32–42)

Outcome: Build tool-using, stateful, reliable AI agents.

Prerequisite: Phase 4 outcomes.

Planned milestone: **AI Customer Support Agent**. [Phase overview](phases/phase-05-ai-agents/README.md).

## Phase 06 — Multi-Agent Systems (Days 43–49)

Outcome: Understand when multiple specialized agents are better than one agent.

Prerequisite: Phase 5 outcomes.

Planned milestone: **AI Business Research Team**. [Phase overview](phases/phase-06-multi-agent-systems/README.md).

## Phase 07 — MCP + Context Engineering (Days 50–56)

Outcome: Connect AI agents to external tools/data and learn to manage context intentionally.

Prerequisite: Phase 6 outcomes.

Planned milestone: **AI Developer Assistant**. [Phase overview](phases/phase-07-mcp-context-engineering/README.md).

## Phase 08 — Fine-Tuning + Model Optimization (Days 57–62)

Outcome: Know when to use prompting, RAG, or fine-tuning and understand practical model optimization.

Prerequisite: Phase 7 outcomes.

Planned milestone: **Specialized classification or extraction model**. [Phase overview](phases/phase-08-fine-tuning-optimization/README.md).

## Phase 09 — LLMOps + Production AI (Days 63–69)

Outcome: Turn AI prototypes into observable, secure, cost-aware production systems.

Prerequisite: Phase 8 outcomes.

Planned milestone: **Production hardening and AWS deployment**. [Phase overview](phases/phase-09-llmops-production/README.md).

## Phase 10 — Production AI Capstone (Days 70–75)

Outcome: Build and deploy one serious production AI product.

Prerequisite: Phase 9 outcomes.

Planned milestone: **Production AI SaaS Capstone**. [Phase overview](phases/phase-10-production-capstone/README.md).
