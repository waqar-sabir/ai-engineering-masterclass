# 75-Day AI Engineering, Agentic AI & System Design Masterclass

A comprehensive 75-day AI Engineering masterclass covering Python, LLMs, RAG, Agentic AI, Multi-Agent Systems, MCP, AI System Design, LLMOps, and production AI applications.

Self-paced, hands-on, project-based learning in English for experienced software engineers transitioning into AI Engineering.

## Learning objectives

- Build grounded RAG pipelines and stateful, tool-using agents.
- Design secure multi-tenant AI systems and MCP integrations.
- Evaluate quality, latency, token usage, errors, and cost.
- Containerize and deploy a production AI application on AWS.
- Present portfolio projects with architecture, evaluation, and deployment evidence.

## Prerequisites and stack

Working software engineering, Git, HTTP/JSON, and command-line skills are expected. See [prerequisites](docs/prerequisites.md).

Python, TypeScript, PostgreSQL, pgvector, Qdrant, LangChain, LangGraph, MCP, FastAPI, Docker, and AWS. Dependencies are introduced only when needed.
