# Prerequisites

Experience writing and debugging software, Git branches and pull requests, shell commands, HTTP APIs, and JSON. Python fundamentals are reinforced in Phase 1.

Use a supported Linux, macOS, or Windows WSL environment, Python 3.12+, uv, and Node.js 22+ with npm. Docker and AWS access are needed only in later phases. GPU access is not required for the repository foundation.

Use synthetic or licensed datasets. Provision provider accounts and spending limits only when a lab requires them.
