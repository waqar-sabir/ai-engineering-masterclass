# Course guide

Study each day through Learn → Build → Test → Document → Commit → Next. Day numbers describe sequence, not calendar deadlines.

Content hierarchy: Phase → Section → Module → Lecture → Resources → Lab → Assessment → Project.

Use paths such as `sections/section-01-topic/modules/module-01-topic/lectures/lecture-01-topic.md` within a phase. Keep resources, labs, and assessments beside their owning module; link projects in the root project catalog. Copy the [templates](../templates/README.md) when a phase is approved for development.

Record status and evidence in [PROGRESS.md](../PROGRESS.md). Passing an assessment requires its published rubric and reproducible evidence; no universal passing score is assumed. Owner approval is required before merging a phase.
