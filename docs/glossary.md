# Glossary

- **Token:** Model input/output unit.
- **Embedding:** Numerical representation used for semantic comparison.
- **RAG:** Retrieval-augmented generation using retrieved context.
- **Agent:** Model-driven workflow that selects tools or actions.
- **MCP:** Model Context Protocol for tool and data integration.
- **LLMOps:** Evaluation, delivery, and operation of LLM applications.
- **Tenant:** Customer or organization whose data requires isolation.
- **pgvector:** PostgreSQL extension for vector storage and search.
- **Grounding:** Supporting generated claims with retrieved evidence.
